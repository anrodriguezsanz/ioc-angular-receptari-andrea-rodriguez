# The Recipe Archive

## Autora
Andrea Rodríguez Sanz

## Descripció
Aplicació per registrar i consultar receptes de cuina.

## Versions utilitzades
- Node.js 24.21.0
- Angular CLI 22.2.1
- npm 11.19.0

## Com crear i executar el projecte
Aquest projecte s'ha creat amb la comanda:
`ng new ioc-angular-receptari-andrea-rodriguez --routing --style=scss --ssr=false --standalone=true --file-name-style-guide=2016 --skip-git=true --package-manager=npm`

Per executar-lo, cal situar-se al directori arrel del projecte i introduïr la següent comanda a la terminal:
 `ng serve`
